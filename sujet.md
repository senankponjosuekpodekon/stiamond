# Stack technique recommandée

* **Framework** : Next.js (App Router, TypeScript)
* **Styling** : Tailwind CSS + shadcn/ui
* **Animations** : Framer Motion
* **CMS** : Payload CMS ou Sanity
* **Base de données** : PostgreSQL
* **ORM** : Prisma
* **Authentification** : Auth.js
* **Déploiement** : Cloudflare Workers + Cloudflare Pages
* **Stockage** : Cloudflare R2
* **Cache** : Redis
* **Recherche** : Algolia ou Meilisearch
* **Monitoring** : Sentry + Umami ou Google Analytics
* **CI/CD** : GitHub Actions

## Estimation de l'ampleur du projet

Ce n'est plus un simple site vitrine mais une **plateforme d'entreprise**.

* **≈ 30 à 40 pages principales**
* **≈ 120 à 180 composants UI réutilisables**
* **≈ 25 à 35 modèles de pages**
* **≈ 80 à 120 animations et micro-interactions**
* **≈ 15 à 25 modules fonctionnels**
* **≈ 150 à 300 pages de documentation fonctionnelle et technique**

À ce niveau de détail, ce document devient le référentiel utilisé aussi bien par les designers, les développeurs, les spécialistes SEO, les équipes marketing et les futurs collaborateurs. Il est suffisamment robuste pour accompagner Stiamond pendant plusieurs années sans devoir repenser complètement l'architecture du site.
