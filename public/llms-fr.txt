# Stiamond Digital

> Ingénierie IA, Logiciel & Cloud — Studio Solo

Stiamond Digital est un studio solo dirigé par Senankpon Josué Kpodekon, aussi connu sous le nom de Stiamond, basé à Cotonou, Bénin. Une seule personne couvre développement, design, marketing, automatisation IA et gestion de projet IT — ce que la plupart des agences répartissent sur 3-4 personnes. Les clients travaillent directement avec le fondateur, pas avec un account manager.

## Expertise (6 Piliers)

- Ingénierie Logicielle : Logiciels sur mesure, plateformes web, produits SaaS (React, Vue, Next.js, Laravel, NestJS, Flutter)
- Ingénierie IA : Intégration LLM, systèmes RAG, agents IA, automatisation intelligente
- Infrastructure Cloud : Architecture scalable, DevOps, CI/CD, déploiement Cloudflare
- Systèmes de Croissance : SEO, stratégie de contenu, automatisation marketing, croissance data-driven
- Automatisation : Agents n8n, orchestration de workflows, optimisation des processus (en production)
- Créatif & Contenu : Créatifs publicitaires, vidéos courtes, funnels Systeme.io, pubs Meta/Google/TikTok

## Résultats Prouvés

- 18+ boutiques e-commerce créées (Shopify, WooCommerce)
- 7+ sites vitrines livrés
- 69+ campagnes publicitaires gérées (Meta, Google, TikTok)

- Core Web Vitals : LCP sous 2,5s, CLS sous 0,1, INP sous 200ms
- Code propre : TypeScript, architecture propre, code reviews
- SEO-ready : Données structurées, meta tags, sitemap, HTML sémantique
